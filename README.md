# PulseGear

# Game Store Platform

Plataforma interactiva de comercio electrónico enfocada en la compra de videojuegos. Se trata de un **proyecto demostrativo** a escala completa que integra la experiencia de usuario y las funcionalidades clave de una tienda real (exploración de catálogo, gestión de carrito, animaciones de interfaz y feedback interactivo), desarrollado para exhibir buenas prácticas de desarrollo Frontend.

> ⚠️ **Nota:** Esta plataforma es un proyecto demostrativo no funcional comercialmente (no procesa pagos ni está lanzada al mercado).

## ✨ Funcionalidades Demostrativas

- **Catálogo de Videojuegos:** Navegación fluida por productos con transiciones interactivas mediante Framer Motion.
- **Carrito de Compras (Estado Global):** Flujo completo de adición, modificación y persistencia de artículos utilizando Zustand.
- **Feedback en Tiempo Real:** Notificaciones visuales e interactivas al realizar acciones de compra gracias a Sonner.
- **Consumo de Datos:** Peticiones e integración de endpoints dinámicos gestionados con Axios.
- **Diseño Moderno & Tipado Robusto:** Construido con la última versión de Tailwind CSS v4 y TypeScript.

---

## 🛠️ Tecnologías Utilizadas

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router / React 19)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Gestión de Estado:** [Zustand](https://zustand-demo.pmnd.rs/)
- **Animaciones:** [Framer Motion](https://motion.dev/)
- **Notificaciones UI:** [Sonner](https://sonner.emilkowal.ski/)
- **Peticiones HTTP:** [Axios](https://axios-http.com/)

## 💻 Instalación y Ejecución Local

Para ejecutar y probar este proyecto localmente en tu equipo:

1. **Clona el repositorio:**
2. **Instala las dependencias:**
   npm install
3. **inicia el servidor de desarrollo:**
   npm run dev
4. **Abre la aplicación:**
   Ingresa a http://localhost:3000 en tu navegador.

📜 Scripts Disponibles
npm run dev: Inicia la aplicación en modo desarrollo.

npm run build: Compila la aplicación para producción.

npm run start: Ejecuta el servidor en modo producción.

npm run lint: Revisa el código en busca de advertencias o errores con ESLint.
